## Use Case 1: Forecast de Demanda PQR — CONCEPTUAL_DESIGN

### Description

Time series forecasting of PQR demand using ARIMA/ETS models to predict monthly incoming case volumes for capacity planning.

### Input Schema (Parquet)

**File:** `pqr_monthly_counts.parquet`

| Column | Type | Description | Validation |
|--------|------|-------------|------------|
| year_month | DATE | First day of month (YYYY-MM-01) | Not null, ≥ 2020-01-01 |
| total_count | INT64 | Total PQR cases received in month | ≥ 0 |
| causa_principal | STRING | Top cause category for the month | Not null, non-empty |
| canal_atencion | STRING | Primary attention channel | Enum: presencial, virtual, telefónico |
| avg_gestion_dias | FLOAT64 | Average resolution time (days) | ≥ 0 |

**Minimum rows:** 24 (2 years of monthly data for reliable seasonality detection)

### Output Schema (JSON)

**File:** `forecast_results.json`

| Parameter | Value | Description |

| cv_folds | 5 | Cross-validation folds for MAPE |

### Reference Script (Pseudocode)

```r
# CONCEPTUAL_DESIGN — Reference script, not production code
library(arrow)
library(forecast)
library(tseries)
library(jsonlite)

# 1. Read input
df <- read_parquet("data/curated/pqr_monthly_counts.parquet")

# 2. Validate minimum data
stopifnot(nrow(df) >= 24)

# 3. Create time series
ts_data <- ts(df$total_count, frequency = 12, start = c(year(min(df$year_month)), month(min(df$year_month))))

# 4. Stationarity test
adf_result <- adf.test(ts_data)

# 5. Fit model
model <- auto.arima(ts_data, seasonal = TRUE, stepwise = FALSE)

# 6. Generate forecast
fc <- forecast(model, h = 6, level = c(80, 95))

# 7. Output JSON
result <- list(metadata = ..., forecast = ..., model_diagnostics = ..., quality_controls = ...)
write_json(result, "data/r_outputs/forecast_results.json", pretty = TRUE)
```

### Error Handling

- If input has < 24 rows: abort with error code `INSUFFICIENT_DATA`
- If ADF test p > 0.05 and differencing fails: warn `NON_STATIONARY_WARNING`
- If Ljung-Box p < 0.05: warn `RESIDUAL_AUTOCORRELATION`
- All errors logged to `data/r_outputs/forecast_errors.log`

### Execution Parameters

### Reference Script (Pseudocode)

```r
# CONCEPTUAL_DESIGN — Reference script, not production code
library(arrow)
library(anomalize)
library(tibbletime)
library(jsonlite)

# 1. Read daily volume data
df <- read_parquet("data/curated/daily_volumes.parquet")

# 2. Validate minimum data
stopifnot(nrow(df) >= 90)

# 3. Convert to tibbletime
df_ts <- df |>
  as_tbl_time(index = date)

# 4. Decompose and detect anomalies
anomaly_result <- df_ts |>
  time_decompose(total_cases, method = "stl", frequency = "7 days") |>
  anomalize(remainder, method = "iqr", alpha = 0.05) |>
  time_recompose()

# 5. Extract anomaly flags
anomalies <- anomaly_result |> filter(anomaly == "Yes")

# 6. Output JSON
write_json(result, "data/r_outputs/anomaly_flags.json", pretty = TRUE)
```

### Error Handling

- If date gaps > 7 consecutive days: abort with `MISSING_DATA_GAP`
- If anomaly rate > 10%: warn `HIGH_ANOMALY_RATE` (may indicate regime change, not anomalies)
- If seasonal strength < 0.1: warn `WEAK_SEASONALITY`, fallback to IQR-only method
- Missing values interpolated via linear interpolation (max 3 consecutive NAs)

| Parameter | Value | Description |

| velocity_window | 7 | Days for velocity calculation |
| min_group_size | 5 | Minimum cases per group (privacy) |
| alert_threshold_days | 3 | Days before SLA breach to alert |

### Reference Script (Pseudocode)

```r
# CONCEPTUAL_DESIGN — Reference script, not production code
library(arrow)
library(dplyr)
library(lubridate)
library(jsonlite)

# 1. Read open cases
df <- read_parquet("data/curated/open_cases.parquet")

# 2. Calculate aging metrics
snapshot_date <- Sys.Date()
df <- df |>
  mutate(
    dias_abierto = as.integer(snapshot_date - fecha_creacion),
    is_overdue = dias_abierto > sla_dias,
    days_to_breach = sla_dias - dias_abierto
  )

# 3. Aging distribution
aging <- df |>
  mutate(bucket = cut(dias_abierto, breaks = c(0, 5, 10, 20, 30, Inf))) |>
  count(bucket) |>
  mutate(pct = n / sum(n) * 100)

# 4. Group analysis (respecting MIN_GROUP_SIZE)
by_cause <- df |>
  group_by(causa) |>
  filter(n() >= 5) |>  # Privacy: MIN_GROUP_SIZE
  summarise(count = n(), avg_age = mean(dias_abierto), overdue_pct = mean(is_overdue) * 100)

# 5. Velocity calculation
velocity <- calculate_velocity(df, window_days = 7)

# 6. Output JSON
write_json(result, "data/r_outputs/backlog_analysis.json", pretty = TRUE)
```

### Error Handling

- If snapshot_date is in the future relative to max(fecha_creacion): warn `FUTURE_DATE_DETECTED`
- Groups with < 5 cases excluded from by_cause/by_analyst (MIN_GROUP_SIZE privacy rule)
- If no open cases: return empty summary with `total_open_cases: 0`
- Negative dias_abierto values (data error): filtered and logged to error output

```r
# CONCEPTUAL_DESIGN — Reference script, not production code
library(arrow)
library(tidyverse)
library(scales)
library(jsonlite)

# 1. Read analyst metrics
df <- read_parquet("data/curated/analyst_metrics.parquet")

# 2. Validate minimum data
stopifnot(n_distinct(df$analyst_id) >= 5)  # MIN_GROUP_SIZE

# 3. Calculate productivity metrics
productivity <- df |>
  group_by(analyst_id, role) |>
  summarise(
    total_resolved = sum(cases_resolved),
    avg_throughput = mean(cases_resolved),
    avg_resolution = mean(avg_resolution_days),
    sla_compliance = mean(sla_compliance_pct),
    rework_rate = sum(rework_count) / sum(cases_resolved) * 100,
    .groups = "drop"
  )

# 4. Quartile classification
quartiles <- quantile(productivity$avg_throughput, probs = c(0.25, 0.5, 0.75))
productivity <- productivity |>
  mutate(performance_tier = case_when(
    avg_throughput >= quartiles[3] ~ "high_performer",
    avg_throughput <= quartiles[1] ~ "needs_support",
    TRUE ~ "on_track"
  ))

# 5. Role-level aggregation (respecting MIN_GROUP_SIZE)
by_role <- productivity |>
  group_by(role) |>
  filter(n() >= 5) |>
  summarise(across(c(avg_throughput, avg_resolution, sla_compliance), mean))

# 6. Trend analysis
trends <- calculate_weekly_trends(df, window = 4)

# 7. Output JSON
write_json(result, "data/r_outputs/productivity_report.json", pretty = TRUE)
```

### Error Handling

- Groups with < 5 analysts excluded (MIN_GROUP_SIZE privacy rule per REQ-09.3)
- If hours_logged = 0 and cases_resolved > 0: warn `MISSING_TIME_DATA`
- If rework_rate > 10%: flag analyst for quality review
- Outlier resolution times (> 30 days) capped and flagged
